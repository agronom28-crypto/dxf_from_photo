# DXF from Photo

Инструмент превращает фото эскиза детали (с рукописными размерами) в два DXF-файла:

1. `*_draft.dxf` — черновой контур, распознанный по фотографии (только геометрия, без проверенных размеров).
2. `*_dimensioned.dxf` — контур с профессионально нанесёнными размерными линиями, диаметрами отверстий и осевыми метками, на основе введённых пользователем проверенных размеров.

## Важно

Черновой DXF (`draft`) нельзя отправлять на резку без проверки размеров человеком. Автоматическое распознавание рукописного эскиза даёт только приблизительную топологию (форму), а не точные размеры. Итоговые размеры всегда должен подтверждать оператор.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Для OCR также нужен установленный `tesseract`:

```bash
# macOS
brew install tesseract tesseract-lang
# Ubuntu/Debian
sudo apt-get install tesseract-ocr tesseract-ocr-rus
```

## Использование

### 1. Черновой DXF из фото

```bash
python src/photo_to_draft_dxf.py examples/sketch.jpg output/draft.dxf
```

Скрипт:
- переводит фото в градации серого,
- усиливает контраст,
- находит контуры (OpenCV `findContours`),
- аппроксимирует их сплайном,
- сохраняет как замкнутую полилинию в DXF (слой `CUT`).

### 2. DXF с профессиональными размерами

Размеры задаются вручную в JSON-файле (после того как оператор проверил их по фото или физическому шаблону):

```bash
python src/build_dimensioned_dxf.py examples/part_spec.json output/dimensioned.dxf
```

Пример `part_spec.json`:

```json
{
  "width": 1830,
  "height": 381,
  "holes": [
    {"x": 52, "y": 22, "d": 10},
    {"x": 485, "y": 22, "d": 10},
    {"x": 938, "y": 22, "d": 10},
    {"x": 1391, "y": 22, "d": 10},
    {"x": 1786, "y": 22, "d": 10},
    {"x": 52, "y": 359, "d": 10},
    {"x": 485, "y": 359, "d": 10},
    {"x": 938, "y": 359, "d": 10},
    {"x": 1391, "y": 359, "d": 10},
    {"x": 1786, "y": 359, "d": 10}
  ]
}
```

Скрипт строит контур, отверстия, размерные цепочки по X, вертикальные размеры, отступы от кромок и подписи диаметров — аналогично тому, как это делает чертёжник вручную.

## Архитектура

```
src/
  geometry.py            — общие функции построения DXF (линии, стрелки, размеры, текст)
  photo_to_draft_dxf.py  — распознавание контура по фото → draft.dxf
  build_dimensioned_dxf.py — построение точного DXF по проверенным размерам → dimensioned.dxf
examples/
  sketch.jpg             — пример фото эскиза (добавьте свой)
  part_spec.json         — пример проверенных размеров
```

## Roadmap (следующие уровни)

- Уровень 1 (готово): параметрический ввод размеров → точный DXF.
- Уровень 2 (готово, черновой): распознавание контура по фото + OCR рукописных цифр (частично, требует ручной проверки).
- Уровень 3 (план): автоматическая привязка распознанных цифр к конкретным сторонам/дугам без участия оператора.
