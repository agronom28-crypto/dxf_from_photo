# Фоновая папка фотографий

При запуске сервис создаёт в рабочей папке:

- `новые фотографии` — входящие JPG, JPEG, PNG, BMP, TIFF, WEBP и PDF;
- `DXF` — результаты и журнал обработки.

```bash
PYTHONPATH=src python src/inbox_watcher.py
```

После полного копирования `заказ 15.jpg` появляются:

- `DXF/заказ 15_dxf_clear.dxf` — чистая производственная геометрия;
- `DXF/заказ 15_dxf_info.dxf` — цифровой чертёж с размерами.

Сервис ждёт стабилизации размера файла, обрабатывает документ во временной папке и перемещает готовые DXF атомарно. Состояние хранится в `DXF/.processing_state.json`; неизменённый файл повторно не запускается. При ошибке создаётся `<имя>_error.json`, а наблюдение продолжается.

Для однократной обработки уже лежащих файлов:

```bash
PYTHONPATH=src python src/inbox_watcher.py --once
```

Текущий адаптер запускает существующие `auto_pipeline.py` или `photo_to_draft_dxf.py`, распознаёт их выходные CNC/DIMENSIONED-файлы и приводит имена к единому формату. Если процессор создал только информационный DXF, чистая версия получается удалением DIMENSION/TEXT/LEADER и размерных слоёв.
