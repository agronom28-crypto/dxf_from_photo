# Графическое уточнение почерка

`clarification_engine.py` не требует подтверждать каждый размер. Значение принимается автоматически, если лучший OCR-вариант имеет достаточную уверенность и заметно превосходит альтернативы. Вопрос создаётся только при отсутствии чтения, низкой уверенности или двух близких разных вариантах.

```bash
PYTHONPATH=src python src/clarification_engine.py build photo.jpg ocr_candidates.json output/review
```

В `output/review/review.html` оператор видит увеличенный фрагмент исходного фото. Неразборчивая надпись отмечена красной рамкой; рядом показаны варианты OCR и поле для собственного значения. Ответы сохраняются как JSON:

```json
{"dim_radius": 35}
```

```bash
PYTHONPATH=src python src/clarification_engine.py apply output/review/review.json answers.json output/resolved_dimensions.json
```

После применения ответов pipeline продолжает параметрическое построение. Если хотя бы на один вопрос нет ответа, CNC-экспорт остаётся заблокированным. Порог по умолчанию — 0.88; его следует калибровать на реальных фотографиях операторов, не снижая ради уменьшения числа вопросов.
