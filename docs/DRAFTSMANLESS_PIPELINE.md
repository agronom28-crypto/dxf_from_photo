# Без чертёжника: производственная логика

Датасет используется как корпус геометрических конструкций и тестов, а не как каталог деталей. Фото-интерпретатор должен сформировать параметрическую construction spec: топологию, размерные переменные и связи. CAD-ядро строит новую точную фигуру; пиксельный контур никогда не отправляется на станок.

## Fail-closed

Экспорт запрещён, если отсутствует обязательный размер, обязательный параметр не использован, контур разомкнут, дуга не соединяется с предыдущим элементом, есть самопересечение, отверстие находится вне детали или оператор не подтвердил итоговую модель. Это позволяет убрать ручное перечерчивание, не заменяя его опасными догадками OCR.

## Запуск

```bash
pip install -r requirements-reference.txt
PYTHONPATH=src python src/draftsmanless_pipeline.py examples/construction_spec_stadium.json output/order
pytest -q tests/test_parametric_cad_kernel.py
```

Результат: точные LINE/ARC/CIRCLE в `order_CNC.dxf`, размерный `order_DIMENSIONED.dxf` и протокол проверки. Следующий интеграционный слой преобразует результат `ocr_dimensions.py` + `dimension_linker.py` в construction spec и задаёт оператору только вопросы по неоднозначным значениям.
